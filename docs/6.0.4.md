# RTRendererAPI 6.0.4

6.0.4 restores the ordinary opaque-scene rendering path without removing the 6.0.3
medium, material, temporal, NVIDIA or programmable-scene features. Public API and GPUScene
ABI contracts remain unchanged; the 6.0.3 ABI snapshot is preserved.

The backend proves opacity from accepted materials, mesh vertex alpha and every mip of
base-color textures. These facts are cached on resource updates. A vacuum frame with no
persistent or frame-local medium boundaries can then use a pinned surface shader with a
single GGX reflection and direct PBR lighting. It avoids the full transport service,
32-boundary path state and optical continuation loops when their work is provably absent.
Sampling, geometry, light/shadow counts, reflection weights and output resolution are unchanged.

Fractional alpha, lightmap-modulated materials, overlays, transmission, camera media and
medium boundaries conservatively retain the complete transport pipeline. Custom GLSL and
SPIR-V programs always retain their original stages and ABI. The full built-in pipeline is
created on demand and cached separately. Both variants stay alive until all submitted frames
have retired, so scene changes never destroy a pipeline still in use by the GPU.

Eight pinned SDR/HDR, diagnostic and SER surface variants ship with core. Production startup
loads SPIR-V directly; it does not invoke shaderc. Driver pipeline persistence retains the
6.0.3 bounded, device-specific cache. A first-ever shader/driver combination can still require
native driver compilation; subsequent runs reuse the persisted pipeline cache.

`DemoPerformanceBenchmark` measures identical frozen demo geometry, separates renderer opening
and first-frame latency, warms the GPU, and reports three measured GPU/completion ranges. Its
public API usage also supports the 5.1.1 runtime for a controlled comparison. Run it with
`:demos:hex-ball:demoPerformanceNativeBenchmark`. Pixel and transport-transition comparison is
available as `:demos:hex-ball:surfacePathNativeSelfTest`.

Delivery consists of source and local build artifacts. No publication to Maven Central is
part of this change. See the [versioned quality report](quality/6.0.4-performance.md) for
measured results and hardware limits.
