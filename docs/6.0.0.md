# RTRendererAPI 6.0.0

6.0.0 是有意进行不兼容变更的版本。Java API、provider SPI 和 retained-scene GPU ABI 开启新的 major line。所有三个已发布 modules 必须使用完全相同的版本。旧别名、位置参数配置构造器和推断式 workload 转换不属于此契约；调用方应在当前 API 中使用类型化 builders 和显式 workload methods。

当前实现提供以下由本版本定义的 contracts：

- 不可变的 renderer configuration、frame requests、scene transactions，以及类型化 lifecycle、capability 和 completion evidence。
- Retained GPUScene uploads，具有显式 resource generations、有界 frame ownership、增量 dirty-range 更新和确定性 retirement。
- 普通 opaque materials 使用 direct first-hit path。声明了 transmission、medium boundary 或 bulk medium 的 frames 使用有序 transport service，而不是让每次 opaque hit 都承担该开销。
- 通用 solid 和 liquid medium transport，包含独立的 extinction、scattering、emission 和 IOR，nested boundary transitions、Snell refraction、Fresnel 与 total internal reflection。
- Temporal reconstruction inputs 携带精确 camera projections、motion vectors 和 dynamic instance revisions；history 有界，并按类型化原因失效。
- Anti-aliasing、temporal、reconstruction、denoising 和 medium policies 可按 frame 设置，并在 frame boundary 根据 device capabilities 验证和选择。
- 显式 command 和 ray-tracing workload contracts，涵盖 versioned resources、shader interfaces、pipelines、render passes、barriers、acceleration structures 和 completion evidence。
- 可选 NVIDIA technologies 表示为 negotiated capabilities 和 execution evidence，不提供隐藏的 compatibility API channel。
- 原生格式 frame views/snapshots，以及可确定释放的显式 Vulkan interop leases。
- Demo 和 publication checks 使用同一组 module coordinates，并保留 FG/MFG 仅在前台验收的语义。

本文是契约索引，不是硬件验收声明。若要声称某个硬件场景已验收，应运行 repository checks，并记录实际 GPU、driver、窗口前台状态、命令输出和 artifact checksums。

此版本只交付到 GitHub 和本地 staging repository，未上传 Maven Central。使用以下命令生成 repository：

```powershell
.\gradlew.bat publishAllToLocalStagingRepository --dependency-verification=strict --no-daemon --console=plain
```

使用以下命令运行完整 CPU 和 publication checks：

```powershell
.\gradlew.bat check verifyPublishedMavenConsumer --dependency-verification=strict --no-daemon --console=plain
```

`6.0.0` ABI snapshot 是新的 major baseline。后续 6.x releases 必须将其公开二进制接口与 `renderer-api/abi/renderer-api-6.0.0.abi` 比较；新的 major line 应使用新的 baseline。
