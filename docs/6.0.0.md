# RTRendererAPI 6.0.0

6.0.0 is the deliberate breaking release. The Java API, provider SPI and retained-scene GPU ABI
start a new major line. All three published modules must use the exact same version. Legacy aliases,
positional configuration constructors and inferred workload conversions are not part of this
contract; callers use the typed builders and explicit workload methods in the current API.

The current implementation exposes these release-owned contracts:

- Immutable renderer configuration, frame requests, scene transactions and typed lifecycle,
  capability and completion evidence.
- Retained GPUScene uploads with explicit resource generations, bounded frame ownership, incremental
  dirty-range updates and deterministic retirement.
- A direct first-hit path for ordinary opaque materials. Frames that declare transmission, a medium
  boundary or bulk medium use the ordered transport service instead of paying that cost on every
  opaque hit.
- General solid and liquid medium transport with independent extinction, scattering, emission and
  IOR, nested boundary transitions, Snell refraction, Fresnel and total internal reflection.
- Temporal reconstruction inputs that carry exact camera projections, motion vectors and dynamic
  instance revisions; history is bounded and invalidated by typed reasons.
- Per-frame anti-aliasing, temporal, reconstruction, denoising and medium policies that are selected
  at the frame boundary and validated against device capabilities.
- Explicit command and ray-tracing workload contracts covering versioned resources, shader
  interfaces, pipelines, render passes, barriers, acceleration structures and completion evidence.
- Optional NVIDIA technologies represented as negotiated capabilities and execution evidence, with
  no hidden compatibility API channel.
- Native-format frame views/snapshots and explicit Vulkan interop leases with deterministic release.
- Demo and publication checks that consume the same module coordinates and preserve foreground-only
  FG/MFG acceptance semantics.

This document is a contract index, not a hardware acceptance claim. Run the repository checks and
record the actual GPU, driver, window foreground state, command output and artifact checksums before
calling a hardware scenario accepted.

The release is delivered to GitHub and the local staging repository only; it is not uploaded to
Maven Central. Generate the repository with:

```powershell
.\gradlew.bat publishAllToLocalStagingRepository --dependency-verification=strict --no-daemon --console=plain
```

Run the complete CPU and publication checks with:

```powershell
.\gradlew.bat check verifyPublishedMavenConsumer --dependency-verification=strict --no-daemon --console=plain
```

The `6.0.0` ABI snapshot is the new major baseline. Future 6.x releases must compare their public
binary surface with `renderer-api/abi/renderer-api-6.0.0.abi`; a new major owns a new baseline.
