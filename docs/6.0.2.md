# RTRendererAPI 6.0.2

6.0.2 is a patch release on the deliberate 6.x breaking line. It keeps the
6.0.x public Java entry points, provider SPI, retained-scene GPU ABI and material/medium
semantics compatible. New precompiled-scene entry points are additive.

Application retained-scene programs may now provide validated SPIR-V stage binaries in addition
to GLSL. Raygen accepts separate SDR and HDR binaries; hit/miss stages use output-independent
binaries. Missing variants compile the supplied GLSL or fail explicitly when no source is supplied.
The runtime never substitutes a built-in shader for an incomplete application variant. This gives applications a standard,
production-grade way to ship shaderc-optimized modules and removes pathological cold-start
optimization cost for large ray-tracing shaders without weakening ABI validation.

The 6.0.1 content-addressed GLSL/SPIR-V cache remains available as a best-effort fallback. Vulkan
pipeline cache and application shader binaries remain separate layers. In-process shader cache
retention is bounded to 64 MiB, disk payloads have SHA-256 checksums, and the cache identity includes
the source, compiler binding version, target environment and compilation options. Invalid binary
headers are rejected at registration; execution model and public descriptor ABI are checked before
pipeline creation. GLSL and binary stages both retain the existing custom-raygen SER policy.

The release is delivered to GitHub and the local staging repository only; it is not uploaded to
Maven Central. Build and consume it locally with:

```powershell
.\gradlew.bat publishAllToLocalStagingRepository --dependency-verification=strict --no-daemon --console=plain
```

The 6.0.0 ABI snapshot remains the major baseline for all 6.x patch releases.

Validation on the NVIDIA GeForce RTX 5080 Laptop GPU:

- Root `check`, demo `check` and complete local staging publication passed (161 tasks).
- Native precompiled-stage checks verified exact SDR/HDR pixels, application buffer generations
  and repeated frame-slot reuse with Vulkan validation enabled; no warnings, errors or dropped messages.
- Four-stage contract checks covered defensive ownership, matching output variants, supplied GLSL
  fallback, absent-variant rejection, incorrect execution models and invalid output-image formats.
- The historical 6.0.0 ABI file is unchanged; a separate 6.0.2 snapshot reviews only compatible additions.

These checks establish API behavior. Host-specific image correctness, cold driver pipeline time,
frame rate and long-frame measurements require separate application acceptance.
