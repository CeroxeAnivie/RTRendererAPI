# RTRendererAPI 5.2.0

5.2.0 adds host-independent, closed-volume participating media to the retained-scene renderer.
The same definitions apply to persistent scene instances, frame-local primitives and the global
environment medium. Surface materials remain independent of volume coefficients; no application
identity, game block type or compatibility adapter participates in transport.

This version is delivered through GitHub source and local Maven artifacts. It is **not uploaded
to Maven Central**. All three modules use 5.2.0 and must be consumed together. The major-5 public
Java ABI is preserved; the new version owns an additive ABI baseline.

## Public contract

`EnvironmentState.Medium` defines homogeneous RGB absorption/extinction, scattering, density,
index of refraction, volumetric emission and Henyey-Greenstein phase anisotropy. Coefficients are
per world-distance unit; density multiplies extinction, scattering and emission, independently of
IOR. `absorption(...)` computes total extinction from absorption plus the final scattering values
at build time. `extinction(...)` explicitly selects total extinction instead. The setters are not
order dependent within absorption mode. Coefficients are finite/non-negative, IOR is at least one,
and anisotropy is strictly between -1 and 1. Boundary scattering cannot exceed total extinction.

`MediumBoundaryState` owns a medium, signed integer priority, winding orientation and a surface
interaction policy. Attach it to either `SceneInstance` or `PrimitiveInstance`. A volume-only
boundary is invisible while retaining extinction, scattering and emission. A surface-interacting
boundary uses its ordinary material's transmission, roughness and color, with IOR transitions
determined by the media on its two sides.

```java
var water = EnvironmentState.Medium.builder()
        .absorption(0.04f, 0.015f, 0.008f)
        .scattering(0.015f, 0.015f, 0.015f)
        .density(1)
        .indexOfRefraction(1.333f)
        .phaseAnisotropy(0.2f)
        .emission(0, 0, 0)
        .build();
var boundary = MediumBoundaryState.builder(water).priority(1).build();
var volume = SceneInstance.builder(100, closedMesh.id())
        .mediumBoundary(boundary).build();
// Register closedMesh and its material before or in the same scene transaction.
// Frame-scoped replacement uses the same boundary semantics:
var transientVolume = PrimitiveInstance.from(volume);
var quality = MediumTransportOptions.builder().maxInterfaceEvents(12)
        .opticalSamples(1).scatteringSteps(8).maximumDistance(512).build();
var frame = RenderFrameRequest.builder(1, width, height, camera)
        .mediumTransport(quality)
        .primitiveBatch(FramePrimitiveBatch.builder().add(transientVolume).build())
        .build();
```

Use either the persistent or transient instance in a scene, rather than duplicating the same
physical boundary in both lanes. `clearMediumBoundary()` removes the role. Immutable copies,
equality and `PrimitiveInstance.from(...)` retain the full medium definition. A batch precomputes
`mediumBoundaryIndices()` so providers can visit only its volume instances.

## Containment and crossings

The camera's initial medium path is classified automatically from accepted mesh generations and
instance transforms, including mirrored/non-uniform transforms and cameras starting inside a
volume. Closed manifold topology is validated on instance admission and on replacement of a mesh
used by a retained boundary. Rejected transactions do not advance accepted scene revision.

The path tracks up to 32 distinct boundary instances. Entering adds that exact instance; leaving
removes it and restores the enclosing medium. The highest priority wins in overlaps. Equal
priorities use latest entry order. When the camera starts inside equal-priority persistent volumes,
stable instance identity supplies a deterministic initial order; transient list order follows it.
The global environment medium is used when no local boundary is active.

Camera nesting above 32 and invalid transient boundary topology produce typed
`FrameValidationException` reasons. Geometry validation checks welded edges, coherent winding,
vertex links, non-degenerate faces and non-zero volume. It does not prove absence of arbitrary
triangle self-intersections. Callers must provide non-self-intersecting, coherently oriented
physical boundaries. Avoid coincident interfaces and camera origins within the renderer's
approximately 1e-3 world-unit ray-offset band; exact surface containment is numerically ambiguous.

Boundary movement, replacement, role removal and retirement invalidate affected medium state.
Persistent and frame-local medium changes also invalidate temporal shading history, including
indirect lighting outside the volume's own visible pixels.

## Transport and quality

- Beer-Lambert attenuation and analytic homogeneous emission integration operate per segment.
- Dielectric interfaces use Snell refraction, exact unpolarized Fresnel and total internal reflection.
  Reflected paths retain the incident medium; transmitted paths cross the boundary.
- The first optical interface splits reflection/refraction by Fresnel weights. Subsequent events
  use deterministic per-pixel bounded Monte Carlo branching. Rough interfaces use GGX sampling.
- Single scattering integrates the HG phase function against ambient environment, sun, point,
  spot and directional lights. Ordered shadow rays account for media and transmissive surfaces.
- Optical/volume pixels avoid the ordinary surface temporal history. NRD signals preserve primary
  attenuation/source contributions and retain the established diffuse/specular signal contract.

`MediumTransportOptions` is editable for every frame, without rebuilding the renderer:

| Setting | Default | Supported range |
| --- | --- | --- |
| continuation/shadow interface events | 12 | 1..32 |
| first-interface optical samples | 1 | 1..8 |
| scattering integration intervals per segment | 8 | 1..64 |
| medium/shadow segment distance | 512 | finite (0, 1,000,000] world units |
| simultaneous boundary instances | fixed capacity 32 | 0..32 |

SPP remains independent; Demo recommends **1 SPP**. Event exhaustion terminates further transport
contributions. Unresolved shadow traversal and path overflow fail closed instead of inventing a
visible background. These are explicit finite quality budgets, not unlimited path tracing.

Scattering is homogeneous RGB **single scattering**. Heterogeneous density fields, spectral
dispersion, full multiple-scattering convergence and focused refractive caustics are not claimed.
Shadow transmittance follows a straight connection to the light; it does not bend that connection
through dielectric interfaces. Rough-interface transport is a bounded real-time approximation.

## Performance and shader ABI

Medium geometry builds one reusable triangle BVH per accepted immutable mesh generation.
Ordinary queries use BVH ray crossings, with alternate directions and generalized-winding fallback
for ambiguous shared edges. Mesh instances share the index. Static camera/batch queries reuse
their results; ordinary surface-only batches and scenes avoid medium containment work.

All secondary optical branches use one continuation call site. The current medium slot is cached
in the local path and recomputed on crossings. Surface lighting, homogeneous integration and
ordered medium shadows share a separately compiled miss service; one PBR surface dispatch evaluates
all of its lights. The mask-zero service dispatch cannot intersect scene geometry. Opaque
non-participating shadow queries retain the direct first-hit fast path inside that service. This prevents the
compiler from multiplying the transport/light loops across every shading branch.

Descriptor binding numbers are unchanged. Instance records grow from 57 to 72 words, frame
uniforms from 404 to 447; their existing prefixes remain intact. Custom scene GLSL must include the
matching `gpuscene_abi.glsl` / `gpuscene_common.glsl`, rather than copy old strides or payloads.
The retained pipeline has one public miss and an internal medium-service miss at index 1, with
depth-two internal ray tracing. Public raygen/miss/hit SBT-region indices remain unchanged. The
explicit resource/command API retains its own user-declared groups and recursion contracts.

## Demo and validation

Run the executable Demo with `--media` (or choose **Medium transport** in the controls workbench).
It exposes RGB absorption/scattering/emission, density, IOR, anisotropy, priority, surface roughness
and transmission, inward winding, nested glass, interior camera, volume-only interfaces,
persistent/transient instances and all four transport quality settings. Apply publishes a validated
immutable state at a frame boundary. HDR display conversion belongs to the Demo.

Automated evidence covers API values/copies, topology rejection and atomicity, accelerated
containment, signed priority, ABI packing, frame-local retirement, temporal invalidation, shader
compilation and native HDR transport scenes. Native values are compared to analytic absorption,
nested-medium restoration, emission, volume-shadow attenuation and TIR expectations; point/spot/
directional/sun scattering are exercised separately. No interactive Demo/FG/MFG acceptance or
Minecraft integration is claimed for this delivery. Performance timings are machine-specific,
informational measurements and are not display-FPS promises.
