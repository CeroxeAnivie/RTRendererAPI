# RTRendererAPI 5.1.1

Repeated GPU arena diagnostics previously traversed every free and retired range and allocated
a new statistics record even when ownership had not changed. The backend now reuses an immutable
statistics snapshot until the arena's existing lifecycle version advances. This applies to all
GPUScene stream arenas and contains no application-specific conditions.

Committed allocations, replacements, removals, resets and completed retirements advance that
version. Preparation, rejected admission and completion polls that release nothing retain the
current snapshot. Earlier snapshots remain immutable. Transaction validation, native ownership,
completion epochs and free-range reuse keep their existing semantics.

The public Java API and GPU ABI match 5.1.0. All three modules use 5.1.1. Tests cover stable reads,
rejected and stale plans, retained snapshots and randomized allocation/retirement accounting
across resets, alignment and free-range coalescing.

This release is delivered through GitHub source and local Maven artifacts. Per the release
instruction, 5.1.1 is not uploaded to Maven Central. The previously published 5.1.0 remains there.
Validation on Windows x64, Java 25 and NVIDIA GeForce RTX 5080 Laptop GPU:

The gate includes the public ABI and core contracts, native GPUScene/acceleration/SER checks,
NRD with camera motion, history resets, resizing and recovered device sessions, DLSS/DLAA/NIS,
local Maven metadata/runtime closure/checksums and an independent published-artifact consumer.
The 5.1.1 public ABI snapshot has the same SHA-256 as 5.1.0:
`c8bbb11c91484746507137f4821435c73b58b938495044a64eef816707f49c9f`.

Frame-generation acceptance uses real foreground windows. FG 2x generated 302 frames, MFG 3x
generated 604 frames, and NRD + DLSS SR + recommended FG 2x generated 302 frames. Each lane
retained 302 consecutive generated samples with successful state queries. Windows foreground
handle observations are recorded in `build/acceptance-foreground-5.1.1.log`; initialization before
foreground activation is not counted as generated-frame evidence. Full execution is recorded in
`build/release-5.1.1-check.log`. The accepted Demo recommendation remains 1 SPP.

Build local Maven artifacts with `publishAllToLocalStagingRepository` (`build/repository`) or
install them with `publishToMavenLocal`. These are local operations; no Central upload is required.
The hardware evidence covers this device and driver, not an unexecuted compatibility matrix.
