# RTRendererAPI 7.1.0

四个 Maven 模块统一为 7.1.0，Java 25。公共接口保持宿主无关，新增能力共用一套 RTXPT 常驻场景和加速结构。

## 执行职责

|入口|主表面|输出与默认策略|
|---|---|---|
|完整 RTXPT|RTXPT 相机射线|完整表面传输，保留原有重建与呈现能力|
|`RtxptRenderers.openNativeLighting(plan)`|独立光照网格的 RTXPT 射线|只请求 gain、有限一跳 GI 和可选辅助；普通配置不执行完整 beauty|
|`openHostSurface(plan, augmentation)`|宿主提供的十面 GPU 输入|保留真实底图 H，按声明颜色域合成 H×gain＋GI；不重复有效主命中|
|`openHostSurface(plan)`，分拆传输|宿主提供的八面 GPU 输入|继续反射、折射与光照，组合结果默认请求 RR；各 radiance AOV 为实际 raw 信号|

普通工厂准备相容配置；完整 `RendererConfig` 重载保留专家显式值并拒绝冲突。详见[普通与专家](ordinary-and-expert.md)。有限确定性光照信号报告实际重建 NONE；不把完整图像 RR 套在 gain 上。

## 修复与新增能力

- 解析灯保留稳定对象与空间索引，局部编辑增量 refit／插入／删除；紧凑稀疏源支持稳定 64 位身份、三种组合、两种衰减及阴影后的可见最大值。
- 宿主输入具有独立资源／输入 generation、revision、时钟、有效性与 ready／done fence；输入已被 GPU 读取后，异常和弃用仍按真实提交退休。
- 分拆输出记录实际 BSDF 与 throughput，直接漫反射、间接漫反射、反射、透射、emission 求和与 raw 组合一致；coverage／cutout、一次 emission 和宿主光照归属均有 GPU 数值对照。
- 主表面传输复用 BUILD／FILL 首 lobe，避免重复 primary。宿主 emission 保留 float 精度，避免原压缩格式把 0.25 改成 0.258。
- 原生光照支持独立网格、精确投影、基准插值、receiver／shadow／bounce 角色、alpha、背面规则、淡入、fog 和应用时钟。修正 shader 矩阵布局及旋转后非均匀缩放的 TRS 分解。
- 应用数据可按范围 patch；HDR／compact 信号明确携带格式、量化契约和实际转换成本。离线扩展使用固定 SDK ABI、DXIL 反射／哈希检查和失败保留旧制品。
- 并发诊断覆盖完整 submit，包括进入 native frame 前的失败；DEEP 立即开始 GPU 采样，OFF 停止新增并异步排空，保留 sequence／revision／generation 关联。
- 可见 Vulkan 呈现窗口在设备和交换链准备完成后主动请求前台，避免后续测试窗口留在后台；仅启动时请求，不在渲染循环中反复抢焦点。

## 本机定向量化

以下为 RTX 5080 Laptop、驱动 616.92 上的实测，具体输入和证据见[性能记录](quality/rtxpt-710-performance.md)。

|项目|优化前|优化后|收益|
|---|---|---|---|
|相同有限光照算法 GPU P50|34.7873 ms|12.5859 ms|耗时 −63.82%，阶段速度 2.764 倍|
|同一阶段 GPU P95|40.6252 ms|16.9441 ms|耗时 −58.29%|
|同一帧阴影射线|66,718,019|11,069,335|减少 83.41%；primary／bounce／光源候选不变|
|4 B 应用数据编辑|4096 B 全量等价|4 B 增量|上传量减少 99.9023%|
|默认两张光照输出的编码像素|16 B HDR|8 B compact|编码输出减少 50%；仍有 HDR scratch 与转换 pass|

GPU 对照固定宿主 2560×1600、光照 1280×800、64 光源、2 GI samples／6／0.35、双 RGBA16F，24 帧预热、120 帧测量。直接光和 GI 共 6,144,000 个 RGB 分量逐位一致；未减少光源、采样或新帧。该对照是本次 7.1 算法优化前后，不是旧 Vulkan 后端或整机 FPS 对照。

## 验收与交付

版本使用 `verifyApiClosure --no-parallel --max-workers=1 -PrtxptTestPackaged` 作为最终全量入口，包含 CPU、真实 GPU、宿主 raw／RR／传输、原生矩阵、持续动态／混合压力、重复 session／resize、Vulkan／NVIDIA 及离仓 Maven 消费者检查。权威结果由 `build/reports/api-closure/result.json` 保存本次任务列表和制品 SHA-256；失败或中断不会留下旧的通过记录。

原始需求映射、已经测到的证据和宿主集成边界见[验收账本](rtxpt-710-acceptance.md)。安装方式和依赖仍见[Java 接入](Java.md)，GPU 扩展及离仓工具见[SDK](rtxpt-710-release-sdk.md)。
