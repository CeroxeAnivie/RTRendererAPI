# RTRendererAPI 5.1.0

This additive release provides an application-owned nanosecond timeline and immutable partial
resource snapshots. Neither feature contains application-specific scene or lighting semantics.
Delivery targets are GitHub source and signed Maven Central artifacts. Local staging and
independent consumer verification precede submission; upload, validation and publication are
separate states and are reported using the actual Central deployment evidence.

## Timeline

`RenderFrameRequest.Builder.clock(FrameClock)` snapshots explicit time and elapsed nanoseconds.
The default is `(0,0)` so legacy request construction stays deterministic. `FrameClock.system()`
samples `System.nanoTime()`; `fromPrevious` derives a nonnegative delta on that timeline.
Signed timestamps and short differences across long wrap are supported. Rewinds are explicit new
snapshots with a nonnegative delta; applications own pause, seek and history reset policy.
Admission retries of one immutable request retain its original time.

The standard GPU ABI appends time at words 400/401 and delta at 402/403. Earlier words retain
their offsets. Use matching API/core/provider versions. GLSL helpers `gsFrameTimeNanos`,
`gsFrameDeltaSeconds` and `gsFrameSecondsSince` subtract integers before float conversion;
future starts clamp to zero. Timestamp differences must be shorter than 2^63 nanoseconds.

## Partial resource updates

`ResourceData.withUpdates(List<Update>)` defensively snapshots replacement ranges. Ranges are
validated before mutation, later overlaps win, and size/order stay fixed. Each snapshot shares
unchanged 16 KiB pages without retaining a chain of parent snapshots. `bytes()` still returns an
independent readonly contiguous view, materialized lazily when needed. Empty update lists reuse
the snapshot; empty replacement ranges and out-of-bounds writes are rejected.

Each GPU frame slot compares against the exact snapshot it previously uploaded. Skipped versions,
branched versions and reuse of older snapshots remain correct. Changed pages are written only
after the slot is free; an upload failure invalidates that slot's comparison cache. Full payload
construction remains supported for arbitrary resizing and unrelated data sources.

## Demo and evidence

The executable Demo opens a feature workbench with independent public renderer and frame policies.
`--controls` opens it explicitly. `--programmable` opens editable retained GLSL stages, HDR preview,
pause/seek/rate and immutable partial-buffer updates. Existing CLI workloads remain available.
Native HDR bytes are preserved; preview tone mapping is a display choice.

Focused API contracts, frame packing and real GPU timeline/partial-update acceptance passed on
NVIDIA GeForce RTX 5080 Laptop GPU in `build/timeline-snapshot-check.log`. Full release, feature
and application performance acceptance are recorded separately when completed. Historical 5.0.0
results are not evidence for this candidate. FG/MFG acceptance requires the actual Windows
foreground render window and sustained authoritative generated-frame counts.
