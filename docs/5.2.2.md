# RTRendererAPI 5.2.2

5.2.2 is the performance correction release for the 5.2 medium transport API. It is delivered to
GitHub and the local Maven repository only; Maven Central remains at 5.1.0. The public API keeps
the complete medium contract: nested solid and liquid boundaries, absorption, emission, single
scattering, Snell refraction, Fresnel, total internal reflection and runtime quality controls.

The ordinary opaque path now restores the direct first-hit shadow visibility fast path when the
frame declares no medium boundary, transmission or bulk medium. Ordered medium shadows remain
available for every frame that needs them. The generic pipeline also keeps the conservative SPIR-V
check that omits an unused internal shadow-service miss for proven single-level custom programs;
dynamic and nested traces retain the full depth-two service.

The API topology admission path uses compact edge pairing and vertex-star checks with cached
immutable results. It preserves seam welding, winding, non-manifold and non-zero-volume checks
while substantially reducing temporary allocation for large closed meshes.

Validation for this release includes API checks, native Vulkan pipeline creation on an NVIDIA
GeForce RTX 5080 Laptop GPU, all 34 pinned shader variants and the six-lane medium transport
benchmark. The benchmark uses the same 960x540, 1 SPP workload for every lane and reports hardware
timestamps; interactive FG/MFG and Minecraft visual acceptance are separate activities.

The 5.1.1 versus 5.2.1 default Demo comparison exposed the regression that this release addresses:
5.1.1 measured 3.01 ms GPU time while 5.2.1 measured 7.08 ms on the same 2560x1494 scene. No
Central publication is part of this release.
