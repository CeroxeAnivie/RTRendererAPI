## 理论与实现

ce9 的两份有界 CPU 后缀各含16次更新，完整场景准备 selfNanos 中位为2.863100／2.683350 ms。本候选将内存 native-lighting 结构批次的独立 BLAS 提前提交至原 graphics queue，同时在 CPU 完整执行原 SDK 场景准备，再提交场景表／TLAS 部分。仅在结构变化且缺失 BLAS 多于1个时提前；其他路径保留原顺序。两个命令对象由同一资源代保活至 graphics／compute 退休，异常路径先等待设备完成。

可重叠上限是 min(CPU准备、实际可执行GPU工作)，不是整个CPU scope都能减少。该假设没有先证明CPU准备对应GPU队列空档；已有在途帧可能覆盖准备，再增加一次提交也可能带来成本。这些是待解释机制，不是本轮已证实的退化根因。本轮完整计时没有支持预期的数毫秒收益，因此不继续扩大测试、也不将方案原样留下。

本方案没有跳过 SDK 准备，不恢复失败的 selective-topology-preparation，也不拆 shader、不做跨队列RR/direct重叠；真实GI/RR、质量、信号复用设置和计时边界不变。
