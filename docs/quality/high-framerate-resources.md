## 最终保留方案

保留串行 fused 光照和真实 GI RR，以及 bitstack 近先遍历、父指针和 dirty 发布、全动态源专用 shader、提前写入 guides/geometry/identity、常用 falloff 指数分支。packed-order 和双队列实现均已从源码、构建清单、SDK 和运行资源中撤回。资源事务、局部 refit、coverage 与 AS 分离、后台退休等已接受修复继续保留。

相对本批 retained-signals，更新帧完整 GPU P50 从 6.538240 降到 5.010016 ms，下降约 23.37%；P95 从 7.462656 降到 5.606112 ms，下降约 24.88%；光照 dispatch P50 从 3.221344 降到 1.724032 ms，下降约 46.48%。正式吞吐从 280.18 增至 290.63 FPS，约提升 3.73%。相对旧发布基线 7.125229 FPS，正式吞吐约 40.79 倍；旧基线的计时范围不同，不计算完整 GPU 时间倍率。

保留候选整体完整 GPU P50/P95/P99 为 3.239136/4.988288/5.457568 ms；复用帧 P50/P95 为 3.234208/3.451584 ms。更新帧 P50 为 5.010016 ms，未达到 4 ms 目标，不能用整体或复用帧替代该目标。

超过 7 ms 的 16 帧全部是更新帧，占全部正式帧 0.1834%、更新帧 2.6667%；复用帧超过 7 ms 为 0，超过 16.7 ms 为 0。序号集中在 155–207、374–438。最慢序号 178 完整 GPU 10.378752 ms，其中光照 3.342208 ms、RR 6.630560 ms、TLAS 0.266336 ms；不能据此断言外部程序或显存容量是根因。逐帧提取见 falloff-branch-spikes.json。

lifetimes 的更新 P50 略低，但吞吐和长尾较差：正式 8,697 帧，超过 7 ms 共 18 帧，包括 5 个复用帧；更新最大值 18.583616 ms。因此保留综合更好的 falloff-branch。

## 已撤实验的证据

新夹具直接建立 RR 场景，其资源历史与旧的连续夹具不同，因此不混用旧参考。相同新夹具的串行与并行输出 42 张 HDR 容差 0 一致；RR 每帧执行、输出身份和范围检查通过。这次串行捕获仅用于隔离参考差异，不算保留候选的新增验收。并行正式性能退化，用户决定撤回；原始失败和成功记录保留。

首次并行尝试发生设备移除，无性能结果。随后隔离共享 read-state 的自动窄化/恢复，并将 compute 独占纹理切换限制为该队列可用状态；启用 DRED 的新候选完成出图。一次成功不足以反推首次设备移除的唯一根因。失败和后续记录分别保留。

证据位于 `build/reports/high-framerate/`：`*-analysis.json`、原始逐帧 CSV、运行制品 SHA-256、阶段日志和 `concurrent-states-signal-reuse-check.json`。合并流程为 `tools/Test-HighFramerateCandidate.ps1`；支持保留已完成阶段和仅做离线比较，不重新生成旧基线。
