# 介质 Demo 验收记录

> 清理说明（2026-11-02）：历史 JSON／CSV／JSONL 等实验原始数据及一次性诊断脚本已清理；本文结论、参数和截图保留。原始文件见[清理前版本](https://github.com/CeroxeAnivie/RTRendererAPI/tree/eb3bc21c8b7559dd847c575ca3f392a2f896d86f/docs/quality)，当前工具与验证入口见[工具说明](../../../../tools/README.md)。

`initial-3scene-window-resize*` 是提交 `9bebb7a` 的首次三场景尝试。混合、玻璃、嵌套三阶段均验证 360 原生帧对应 720 实际呈现帧、SDK 查询错误 0。第四阶段窗口输出从 1920×1080 变为 2560×1494，旧测试把截图尺寸写死为 1920×1080，因而断言失败；HUD 和 PNG 都准确记录了新的实际尺寸，没有白屏。此尝试不记为完整验收通过，也不能把不同输出尺寸的耗时混作同一基准。

后续测试按实际窗口尺寸验证截图，并增加原生下拉选择器、六种支持场景及真实场景会话路由。最终验收数据另列，不覆盖首次记录。
