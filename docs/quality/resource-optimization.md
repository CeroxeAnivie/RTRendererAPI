719 稳定场景本次吞吐和 GPU P95 退化；977 稳定场景改善，4096 稳定 P95 略差。结果均保留，没有归因于未经证明的外部 GPU 干扰。4096 流入 GPU P95 约减半，仍高于 4 ms。完整 CPU 请求包含 apply、所有准入尝试及暂停，不能用同步调用代替。

实际改动：

- 双队列完成后复用 TLAS 和 sub-instance buffer，池上限四项／64 MiB；pooledTlasBytes 单列两类存储的引用字节。
- 每代 mesh 回收预算由四项改八项，普通五 mesh 流入不再固定丢掉一项。
- 复用反向依赖 map、列表和 scratch；通过稠密索引加指针核对存活，去掉全表排序和二分查找。
- 拓扑元数据按连续脏区间上传；geometry epoch 和稳定 map-value 地址避免重复哈希，移除身份时同时释放属性。
- 全布局角色候选更新复用 vector；双分组 DEEP 使用匹配的两分组 shader。
- 全 L1 光源使用更紧的保守支持域；尚无 winner 时跳过无效 score 计算。叶子、遮挡、GI 样本与组合保持；没有实测收益的 wave 汇总计数已撤回。

最终 DLL 验证通过：共享／最后实例删除 48 轮、105 个真实 RR 输出；八批拓扑增删后三种信号逐位一致；4096 矩阵覆盖流入、局部、coverage、共享 mip、慢消费者和奇数尺寸。保留相同七个 native shader 包上的十个计数排列与三信号逐位一致，以及 22,275 个 exhaustive oracle 样本，最大 half 误差 0.0009764433，涵盖 POINT/BOX/SPOT、全 L1/mixed 切换与动态增删。

两个子代理按 shader 与资源路径分工，编译/GPU 统一串行。Java 更新路径未发现当前 native 场景全表复制，没有扩展修改无关 HostSurface 模式。没有跑 FG/MFG，也没有重复未受影响的全量验收。
