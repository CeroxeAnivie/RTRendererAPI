# RTXPT 托管介质路径替换规范

## 已确定的执行范围

以 NVIDIA RTXPT v1.9.0（提交 `303b408ab81790a5051abd7573830b7a4112eb8e`）替换原来的介质后端。移除原后端模块、JNI、原生依赖、配置入口、专用测试和回退路径。普通 Vulkan／弹球路径保持独立。

Java 只负责公共接口、场景事务、窗口控制和薄的原生资源桥接。实体、反射、折射、吸收、光追、光照缓存、降噪与重建采用上游机制，不重新维护参与介质渲染算法。正式路径必须常驻于进程内；禁止将启动测试 EXE、截图、逐帧 CPU 图像搬运包装成高性能接入。

混合场景把 RTXPT 计算反射、折射和遮挡所需的几何、材质与灯光交给同一上游渲染场景。普通路径只承担其独立场景或明确的界面合成，不把互不知情的两张图冒充正确的混合光传输。

## 功能收缩合同

| 能力 | 本次目标 | 约束 |
|---|---|---|
| RGB 均匀吸收、厚度引起的透射颜色变化 | 保留并验证 | 映射上游 attenuation color/distance；不能混入不支持的散射系数 |
| 透明介质反射、折射、粗糙透射、IOR | 保留并验证 | 使用上游标准材质；不承诺与旧材质逐像素一致 |
| 嵌套介电材质优先级 | 保留上游可表达范围 | 映射范围、并列规则、嵌套数量必须明确；不默默截断 |
| 表面 PBR、法线/材质纹理、表面发光、上游灯光 | 保留可表达部分 | 不支持的材质组合在提交时拒绝，不静默替换 |
| DLSS-RR、超分辨率、NRD、SHaRC、RTXDI、SER、OMM、Reflex | 按上游和硬件能力接入 | 区分可选择、实际启用和经验证；默认性能验收 FG 关闭 |
| 均匀介质单次及多次体积散射 | 撤下 | 上游默认桥接 sigmaS=0，主路径未接完整体积散射事件；本次不自行补算法 |
| HG 各向异性 | 撤下 | 存在数据字段不等于有完整执行路径 |
| 异质密度网格及程序密度 | 撤下 | 不改成平均密度冒充支持 |
| 体积自发光 | 撤下 | 不改成表面发光冒充支持 |
| 旧逐介质积分步数、散射光样本、散射反弹控制 | 撤下 | 采用上游可用渲染设置，不保留无效开关 |
| 相机初始介质及无限介质 | 未验证前不声明 | 不能仅凭封闭表面吸收通过测试就宣称支持 |
| 任意 BSDF 混合、任意叠层和自定义着色 | 仅保留上游明确支持部分 | 不支持的场景明确拒绝；普通 Vulkan 自定义能力另属原路径 |

撤下必须直接收缩公共 API 参数列表：删除不支持的字段、构造参数、builder/with 方法、demo 控件和对应功能测试，不保留无效占位，也不以“保留旧参数、提交时拒绝”作为最终实现。开发文档逐项记录破坏性变更和迁移方式。支持清单、公共签名与实际执行路径必须一致。

## 实施与验收规则

1. 单代理执行，只在 main 留存成果；全量提交并上传，测试前保留可恢复版本。
2. 源码及依赖固定版本；保留许可证。网络代理只设于本机进程环境，不写入通用项目配置。
3. 构建进程树内存上限 10 GB，UTF-8；不启动 computer use。
4. 优先使用上游完整的 D3D12 执行链。窗口由项目控制，GPU 输出直接呈现；截图读回仅供显式捕获和验证。
5. 先通过接口收缩、材质/场景更新、窗口生命周期及正确性测试，再测 1080p 输出、FG 关闭的真实完成帧。内部渲染分辨率和重建模式分别记录。
6. 仅在实际执行通过后标记功能完成；官方样例的历史 FPS 不能当成本项目新 JNI 后端的验收成绩。
