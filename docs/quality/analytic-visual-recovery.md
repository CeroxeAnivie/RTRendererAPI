## 原则与通用接入

RTXPT 原文件保持官方版本；唯一内部补丁仍是已批准的非交互进度窗 guard。最终原生构建校验 20 仓／4426 原文件未改，额外源文件 0。独立 RtrAnalyticBeauty.hlsl 通过 SampleRenderCode 虚函数、原场景绑定和原命令列表执行，没有改写或宏替换上游函数、注入原生源文件。

新增公开 PathTracingQualityOptions.withBeautyTransport(BeautyTransport.ANALYTIC_DIRECT)。默认和旧构造器保持 NATIVE。shader 不含弹球名称、材质 ID 或几何特判，所有 API 消费者可显式选择同一条路径。原生文件场景与独立有限灯光信号模式不能混用此模式。

本模式明确保持旧解析语义：有限半径衰减、RGB 透明边界可见性、四个界面确定性分叉、后续固定序列原生 BSDF 续光、主表面金属镜面反射。没有漫反射间接光；1 SPP／FULL，禁用 NRD、RR、ReSTIR、SHaRC，不能冒充完整原生积分器。原生 SR、曝光、Bloom、色调映射与 Present 继续由上游执行。

相交、alpha test、场景／AS、纹理／材质解码、Fresnel、delta lobes、GGX、散射推进、嵌套介质、吸收与运动向量均调用原函数。自有部分仅为 RGB visibility 累乘、有限衰减、解析分支调度与接线。镜面反射直接调用 FalcorBSDF.specularReflection.sample，不维护第二份 BRDF/GGX。六个 shader 变体覆盖 nested quality 0/1/2、fp16 0/1。解析 inline compute 没有 SER，最终状态如实上报；请求 REQUIRED SER 会拒绝。

## 代码根因与修复

1. 旧版用自有解析 NEE 和确定性光路替换过上游 shader；新接线只迁参数，没有迁这两条语义。原生 visibility 为 bool，不能产生旧 RGB 透射阴影。现在由独立 API 通道逐透明边界累乘，调用原生相交、材质和 Fresnel；共同光程前缀只着色一次后分叉。
2. 首版外部通道对半金属表面调用完整 StandardBSDF.sample，抽到了旧版没有的漫反射续光并带入随机 lobe 权重，地板出现大面积颗粒。改为只调用原生镜面 lobe，保留旧主表面金属权重和固定序列。不加 SPP、不靠模糊／去噪遮掩。
3. 点灯强度曾被改成参考点标定，无法全距离匹配旧半径衰减。弹球恢复原 authored 强度，显式解析模式执行外部有限衰减；原生默认模式不变。
