# RTRendererAPI 6.0.1

6.0.1 is the first patch release on the deliberate 6.x breaking line. It keeps the
6.0.0 public Java API, provider SPI, retained-scene GPU ABI and material/medium
semantics unchanged.

This release adds a content-addressed cache for application GPUScene shader source:
fully expanded UTF-8 source, resource path, shader stage, HDR output and SER options
form the cache identity. Validated SPIR-V is retained in-process and persisted under
`%LOCALAPPDATA%\RTRenderer\shader-cache` (or the documented override). Cache reads and
writes are best effort; an unavailable or corrupt cache never changes rendering
correctness. Concurrent renderer openings in one JVM share one compilation future.

The cache addresses the cold-start CPU shaderc cost. Vulkan pipeline cache and this
SPIR-V cache are separate layers: the former caches driver pipeline state, while this
release avoids recompiling identical application GLSL. The cache is invalidated by
source or option changes through its SHA-256 identity.

The release is delivered to GitHub and the local staging repository only; it is not
uploaded to Maven Central. Build and consume it locally with:

```powershell
.\gradlew.bat publishAllToLocalStagingRepository --dependency-verification=strict --no-daemon --console=plain
```

The 6.0.0 ABI snapshot remains the major baseline for all 6.x patch releases.
