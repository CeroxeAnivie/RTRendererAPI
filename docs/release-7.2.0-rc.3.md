# 7.2.0-rc.3：区域索引增量维护候选

仅发布 Maven Local，用于真实宿主验收；尚非正式 7.2.0。保留 rc.1、rc.2 制品和失败证据，不发布 GitHub 二进制。

rc.2 已消除粗大全局根导致的 GPU 遍历退化，但真实 MC 移动时仍反复全量重包、上传约 5.7～10.25 MB 区域表，UPDATE P95 从 7.1.7 的 9.6862 ms 增至 20.5475 ms。此项责任在通用 API，不能通过宿主少报真实光源变化规避。

本候选消费光源 BVH 的权威脏节点，只维护变化前沿和受影响格链接。哈希槽位与列表块保持稳定，列表块分级复用，仅上传变化的 64 B 范围；邻近小间隙合并，减少短上传调用。颜色、强度或覆盖格未变化的微移不写区域表。完整重包保留于初始化、容量增长、全局前缀增长及累计 tombstone 超阈值后的摊销压缩。

删除保留哈希探测链；零号根写入新列表块也强制上传，避免 CPU 零值与未初始化 GPU 容量混淆。光源、画质、GI、真实 RR 和计时边界不变。CPU 增量/上传 oracle 与 raw、真实 RR 定向结果记录在 `build/reports/resource-root-followup/rc3-incremental-region-check/`。正式接受仍需同条件真实 MC 移动结果；机制改善不代表 FPS 已获收益。
